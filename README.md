# 科普视频审稿台 · 网页

这里只有程序，不含任何讲稿、配音或审稿结果。内容都在私有仓库里，用 GitHub 口令登录后才取得到；口令只存在你自己电脑的浏览器里。

怎么用：打开网页 → 填审稿仓库（账号/仓库名）和口令 → 先选领域 → 再选哪一步：

1. **三选一**：三版盲挑。选总体用哪版；哪一段想用别版，点那一栏的「用这版」；想改字，点开那段底下的「改这一段」，把选中的那版填进来改，或者整段重说。
2. **细改**：配音之前对着整篇文字改。点哪句改哪句，清空就是删掉，回车在后面加一句，整场要改得多就「整段重说」。改定了才去配音。
3. **听评**：对着配音听有没有念错、停顿不对，做最后的微调。

填到一半关掉也不怕：内容自动存在这台电脑的浏览器里，再打开接着填；点「退出」会把口令和草稿一起清掉。
语音输入用系统自带的就行：点进文字框后，Windows 按 Win+H，Mac 按两下 Fn，手机用输入法上的话筒。

源码和说明在科普视频仓库的 `desk/` 与 `pipeline/desk.py`。

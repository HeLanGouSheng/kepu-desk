科普视频审稿台

内容都在私有仓库里，登录后才看得到。口令只存在这台电脑的浏览器里，只用来读写审稿仓库。

口令怎么生成（第一次用看这里）
  1. 在 GitHub 网站右上角点头像 → Settings → 左边最下面 Developer settings → Personal access tokens → Fine-grained tokens → Generate new token。
  2. 名字随便起（比如「审稿台」），有效期按需要选。
  3. Repository access 选 Only select repositories，选上面那个审稿仓库。
  4. Permissions → Repository permissions → Contents 选 Read and write（别的不用动）。
  5. 点 Generate token，复制那串字（只显示这一次），贴到上面。

在 Fine-grained tokens 里选不到这个仓库的话（你是被邀请进来的协作者时可能这样），改用 Tokens (classic) → Generate new token (classic)，勾 repo。

片子状态

点「开始」就认领了这一集（别人能看到是你在做）；做完点页面底下的提交按钮。列表每分钟自己刷新一次。
